# Android Lab - Harmless APK Analysis

## About
A harmless Android test application built for learning Android
APK compilation, signing, and static analysis in Kali Linux.

## Features
- Simple Android UI
- Button interaction test
- APK package and SDK inspection
- Permission verification
- APK signature verification
- SHA-256 hash documentation

## Package
com.example.harmless

## SDK
- Minimum SDK: 23
- Target SDK: 35

## Tools
- Kali Linux
- Java
- Android SDK Build Tools
- AAPT
- D8
- Zipalign
- Apksigner

## Safety
This project does not require sensitive Android permissions.
Private signing keys and compiled APK binaries are excluded
from this repository.
